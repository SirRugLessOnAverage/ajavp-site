---
description: Planeia, implementa e testa uma nova funcionalidade de ponta a ponta
---
1. Analisa os ficheiros existentes relacionados com o pedido e cria um plano de implementação (arquitetura, base de dados e UI).
2. Aguarda a minha aprovação do plano antes de escrever código.
3. Implementa o código seguindo as regras do `GEMINI.md` e do `AGENTS.md`.
4. Executa `npx tsc --noEmit` e `npm test` no terminal para confirmar que não há regressões.
5. Executa `npm run build` para validar a compilação completa de produção.
